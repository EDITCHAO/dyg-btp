   🔧 PROBLEMES FREQUENTS

❌ Le logo ne s'affiche pas ?

   → Vérifiez le nom : logo-dyg-btp.png (minuscules)
   → Vérifiez l'emplacement : frontend/public/

   → Modifiez dans : frontend/public/css/dyg.css
   → Ligne : .logo img { height: 70px; ... }

❌ Pas d'effet hover ?

   → Vérifiez que le CSS est bien chargé
   → Ouvrez la console (F12) pour voir les erreurs
