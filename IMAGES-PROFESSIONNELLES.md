## ⚡ Caractéristiques Techniques

### Paramètres d'Optimisation Unsplash
- **w=800 ou w=600 ou w=1200**: Largeur optimale selon l'usage
- **q=90**: Qualité d'image à 90% (excellent compromis qualité/poids)
- **auto=format**: Format automatique (WebP pour navigateurs compatibles)
- **fit=crop**: Recadrage intelligent pour respecter les proportions
- **crop=faces**: Pour les portraits d'équipe, centrage sur les visages

### Avantages
✅ **CDN Global**: Chargement rapide partout dans le monde  
✅ **Responsive**: Images adaptées à tous les écrans  
✅ **Optimisées**: Compression intelligente sans perte de qualité  
✅ **Professionnelles**: Photos de haute qualité spécifiques au génie civil  
✅ **Cohérentes**: Style visuel uniforme sur tout le site
