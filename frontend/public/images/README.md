# 📸 Guide des Images DYG-BTP

Ce dossier contient toutes les images du site. Les fichiers actuels sont des **placeholders SVG** que vous pouvez remplacer par vos propres photos.

## 🎯 Comment remplacer les images ?

**Simple :** Remplacez les fichiers SVG par vos photos en **gardant exactement le même nom**.

### Exemple :
- Vous avez une photo de pont : `mon-pont.jpg`
- Renommez-la en : `projet-pont.jpg` (ou `.png`)
- Placez-la dans ce dossier
- Le site utilisera automatiquement votre nouvelle image !

## 💡 Conseils pour les photos

### ✅ Formats acceptés
- `.jpg` / `.jpeg` (recommandé pour photos)
- `.png` (recommandé pour logos/icônes)
- `.svg` (actuel, peut être gardé)
- `.webp` (moderne, plus léger)

### 📐 Tailles recommandées
- **Hero / Domaines / Projets :** 600x400px (ratio 3:2)
- **Équipe :** 400x400px (carré)
- **Poids max :** 500 Ko par image (pour performance)

### 🎨 Qualité des photos
- **Résolution :** Minimum 72 DPI pour web
- **Luminosité :** Photos bien éclairées
- **Cadrage :** Professionnel (éviter selfies)
- **Style :** Cohérent sur tout le site

## 🔧 Modification rapide

### Via Windows :
1. Ouvrez ce dossier : `c:\PROJET\dyg-BTP\DYG-BTP\frontend\public\images\`
2. Glissez-déposez vos photos
3. Renommez-les selon les noms ci-dessus
4. Rafraîchissez le navigateur (Ctrl + Shift + R)

### Via code :
Si vous voulez changer le nom du fichier dans le code HTML :
```html
<!-- Avant -->
<img src="images/hero-construction-pont.svg" alt="...">

<!-- Après -->
<img src="images/mon-image-perso.jpg" alt="...">
```
