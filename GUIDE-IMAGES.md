# 📸 Guide : Ajouter Vos Propres Images au Site DYG-BTP

## ✅ C'est Fait !

Le site est maintenant configuré pour utiliser **VOS PROPRES IMAGES** depuis le dossier local `images/`.

Plus besoin d'Unsplash ou d'Internet pour les images !

---

## 📍 Où Mettre Vos Images ?

### **Dossier à utiliser :**
```
c:\PROJET\dyg-BTP\DYG-BTP\frontend\public\images\
```

---

---

## 🎯 Comment Ajouter les Images ?

### **Étape 1 : Préparez vos photos**
- Prenez ou sélectionnez vos meilleures photos
- Renommez-les avec les noms ci-dessus
- Format : JPG ou PNG

### **Étape 2 : Placez-les dans le dossier**
1. Ouvrez l'Explorateur Windows
2. Allez dans `c:\PROJET\dyg-BTP\DYG-BTP\frontend\public\images\`
3. Copiez vos 15 images dans ce dossier

### **Étape 3 : Vérifiez les noms**
- Les noms doivent correspondre **EXACTEMENT**
- Attention aux majuscules/minuscules
- Extension `.jpg` ou `.png`

### **Étape 4 : Testez le site**
1. Ouvrez `frontend/public/index.html`
2. Rechargez avec `Ctrl + F5`
3. Vérifiez que toutes les images s'affichent

## 🎨 Conseils de Qualité

### **Pour les Photos de Chantier**
- Lumière naturelle (éviter le contre-jour)
- Angles valorisants
- Équipements de sécurité visibles
- Netteté et bonne résolution

### **Pour les Portraits**
- Fond neutre ou contexte professionnel
- Éclairage uniforme
- Tenue professionnelle
- Cadrage serré sur le visage

### **Pour les Projets**
- Projets terminés et propres
- Plusieurs angles si possible
- Mettre en valeur le travail réalisé
- Photos de jour pour meilleure luminosité

## 🆘 Problème ?

### **Image ne s'affiche pas ?**
1. Vérifiez le nom exact du fichier
2. Vérifiez qu'il est dans le bon dossier
3. Rechargez avec `Ctrl + F5`
4. Vérifiez l'extension (.jpg ou .png)

### **Image déformée ?**
- Respectez les dimensions recommandées
- Utilisez des images de bonne qualité
- Le site adapte automatiquement les proportions

### **Image trop lourde ?**
- Compressez avec TinyPNG.com
- Réduisez la résolution à 72 DPI
- Cible : 200-500KB par image
