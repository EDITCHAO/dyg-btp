## 📍 Localisation des Fichiers

Le site principal se trouve dans:
```
c:\PROJET\dyg-BTP\DYG-BTP\frontend\public\index.html
```

---

## 🚀 Méthodes pour Ouvrir le Site

### **Méthode 1: Double-Clic** (Plus Simple)
1. Ouvrez l'Explorateur Windows (`Win + E`)
2. Naviguez vers: `c:\PROJET\dyg-BTP\DYG-BTP\frontend\public\`
3. **Double-cliquez** sur `index.html`
4. Le site s'ouvre dans votre navigateur par défaut

### **Méthode 2: Depuis VS Code**
1. Dans VS Code, ouvrez le panneau Explorateur (à gauche)
2. Naviguez vers `frontend/public/index.html`
3. **Clic droit** sur le fichier
4. Sélectionnez **"Open in Default Browser"** ou **"Reveal in File Explorer"**

### **Méthode 3: Copier-Coller dans le Navigateur**
1. Ouvrez votre navigateur (Chrome, Firefox, Edge...)
2. Dans la barre d'adresse, copiez-collez:
```
file:///c:/PROJET/dyg-BTP/DYG-BTP/frontend/public/index.html
```
3. Appuyez sur **Entrée**

### **Méthode 4: Via Live Server** (Recommandé pour le développement)
1. Dans VS Code, installez l'extension **"Live Server"**
2. Ouvrez `frontend/public/index.html`
3. Clic droit → **"Open with Live Server"**
4. Le site s'ouvre avec rechargement automatique

## 🔧 Dépannage

### **Les images ne s'affichent pas ?**
1. Vérifiez votre connexion Internet (images hébergées sur Unsplash CDN)
2. Désactivez les bloqueurs de publicité temporairement
3. Essayez un autre navigateur
4. Videz le cache du navigateur (`Ctrl + F5`)

### **Le style ne s'applique pas ?**
1. Vérifiez que le fichier CSS existe: `frontend/public/css/dyg.css`
2. Ouvrez la console développeur (`F12`) pour voir les erreurs
3. Assurez-vous que les chemins relatifs sont corrects

### **Erreurs JavaScript ?**
1. Ouvrez la console (`F12`)
2. Vérifiez les fichiers JS: `frontend/public/js/dyg.js`
3. Rechargez la page avec `Ctrl + F5`
